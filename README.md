# 🎬 YT Movie Skip Intro

A smart, lightweight browser extension that adds a Netflix-style **"Skip Intro"** button directly to the YouTube player for movies (2+ hours). It skips opening titles, studio logos, and credits based on YouTube's replay heatmap and saves your preferred timing locally.

---

## ✨ Features
- ⏱️ **Auto-Detection for Movies:** Only appears on videos longer than 2 hours.
- 🎯 **Smart Jump:** Uses YouTube replay curves and chapters to jump to the actual movie start (capped safely under 3.5 minutes).
- 🧠 **Self-Learning Cache:** Remembers your adjusted skip times locally for future plays.
- 🔒 **100% Private & Safe:** Zero tracking, zero analytics, no dangerous permissions required.

---

## 🚀 How to Install

1. Download the latest release from the [Releases](https://github.com/Prashant19903/yt-movie-skip-intro/releases) section (or download this repo as a ZIP).
2. Extract/Unzip the downloaded folder on your PC.
3. Open your browser's extensions page:
   - **Chrome:** `chrome://extensions`
   - **Edge:** `edge://extensions`
   - **Brave:** `brave://extensions`
4. Turn ON **Developer mode** (top-right corner).
5. Click **Load unpacked** and select the extracted folder.
6. Open any 2hr+ movie on YouTube, and enjoy 1-click intro skipping!
